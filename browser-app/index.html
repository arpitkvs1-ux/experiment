Setup guide

First-time setup for this project: Google Sheet, Apps Script, web app URL, and branding. Keep this page in sync when the process changes (edit index.html in the browser-app folder, section view-setup).

  1. Create the Google Sheet

    Create a new Google Spreadsheet. Add two tabs named exactly Master and Marks (capital M).

    On Master, row 1 must be your student column headers — same names you use in CSV / this app (e.g. R.NO., Student Name, house, …). Data starts row 2. The app syncs this tab into local storage.

    The Marks tab is filled by the Apps Script backend (slip rows). You do not need to create headers by hand; the script can create them on first save. Optional: leave the tab empty until you deploy.

  2. Apps Script project

    In the spreadsheet: Extensions → Apps Script. Add these files from the repo folder google-apps-script/:

    • Code.gs — main API (doPost, doGet, marks CRUD, students read).
    • TeacherMarks.html — teacher marks UI (?teacher=1).
    • TeacherMarksPdfInclude.html — PDF helper included from the teacher page.

    In Code.gs, set CONFIG.SPREADSHEET_ID to your workbook ID (from the Sheet URL). Set CONFIG.SCHOOL_NAME and CONFIG.SCHOOL_CLASS to match the dashboard (see step 5).

  3. Deploy the web app

    Deploy → New deployment → type Web app. Execute as: Me. Who has access: Anyone (or your org policy).

    Copy the deployment URL — it must end with /exec.

    Teachers open the same URL with ?teacher=1 (the teacher page lets them pick exam and subject).

  4. Point the dashboard at the web app

    In browser-app/sheets-webapp-config.js, set window.KV_SHEETS_WEB_APP_URL to that /exec URL (no extra query string). This file is the single source for the browser app; the Android build copies browser-app via Gradle — do not maintain a second copy by hand.

    Reload the dashboard. Open Marks — slips should list from Sheets after sync.

  5. School name and class (branding)

    In sheets-webapp-config.js, set KV_SCHOOL_NAME and KV_SCHOOL_CLASS. Use "—" or "" for class to hide the class line where supported.

    Set the same values in Apps Script CONFIG.SCHOOL_NAME and CONFIG.SCHOOL_CLASS so the teacher page and PDF slips match.

  6. After code changes

    Apps Script: Save, then Deploy → Manage deployments → edit → New version → Deploy.

    Dashboard: Refresh the browser (hard refresh if cached). Android: Run Gradle copyBrowserApp / rebuild if you changed browser-app.
